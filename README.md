# QC Team Workboard

제품분석팀의 개인별 업무 일정을 주간 단위로 확인하는 **Non-GMP 업무 보조용 공개 테스트 버전**입니다.

## 현재 기능

- 직원별·날짜별 주간 일정 보기
- 선택 날짜의 전체 업무 보기
- 업무 등록, 수정, 삭제
- 업무 카드를 드래그하여 날짜와 담당자 변경
- 상태 및 검색 필터
- 브라우저 로컬 저장

## 중요 안내

현재 버전은 시제품으로, 데이터가 각 브라우저의 `localStorage`에 저장됩니다.  
여러 사용자가 동일한 일정을 공유하려면 Supabase 데이터베이스와 로그인 기능을 연결해야 합니다.

- 공식 시험기록은 LIMS 및 관련 기록서에서 관리합니다.
- 실제 시험 결과, 제조번호, 직원 개인정보 또는 비밀키를 저장소에 올리지 않습니다.
- Supabase 키는 향후 Vercel 환경변수로 관리합니다.

## 실행

별도의 설치 없이 `index.html`을 브라우저에서 열면 실행됩니다.

## 배포

Vercel에서 이 GitHub 저장소를 가져오면 정적 사이트로 배포할 수 있습니다.
